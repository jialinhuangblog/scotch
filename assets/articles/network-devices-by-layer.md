# 拆封包拆到第幾層，決定它是什麼設備

同一條網路線，流過的是同一串位元。但一台 switch 跟一台 router 對這串位元做的事，完全不同。

差別藏在一個問題裡：它讀到多深。

## 封包是一層包一層

一個封包不是一坨資料，是[一層一層包起來](chunk://encapsulation)的洋蔥。最外層是 L2 的框（frame），裡面包著 L3 的封包（packet），再裡面是 L4 的段（segment），最內層才是你的資料。

每一層的外皮上，都寫著那一層的地址。L2 的皮上是 [MAC 位址](chunk://arp)，L3 的皮上是 IP 位址，L4 的皮上是 port。

一台設備「工作在第幾層」，意思就是：**它拆到第幾層的皮，讀那層的地址來做決定**。讀得越深，能做的判斷越複雜，處理也越慢。這就是所有網路設備的分類軸。

## 從笨到聰明，一台一台看

**Hub，L1。** 它什麼皮都不拆。一個孔進來的訊號，原封不動複製到其他每個孔。它不知道地址，也不在乎誰是收件人，用喊的。早就被淘汰了，這裡只是當對照的起點。

**Switch，L2。** 它拆第一層皮，讀 MAC 位址。它心裡有一張表，記著「哪個 MAC 掛在哪個孔」，所以封包進來，它只送到對的那個孔，不吵到別人。但它的視野只到「同一個區網內部」，跨不出去。你辦公室裡設備對設備互傳，走的就是 switch。

**AP，L2。** 它本質是一台無線版的 switch。它做的事是翻譯：把 WiFi 的無線框（802.11）轉成有線的乙太框（802.3），反過來也一樣。它一樣讀 MAC、一樣不路由。所以純 AP 跟 switch 是同一層的親戚，只是一個接無線、一個接有線。

**Router，L3。** 它拆到第二層皮，讀 IP 位址。IP 才有「跨網路」的概念，所以 router 的工作是在不同網路之間轉，決定封包的下一跳往哪走。你辦公室要連到 internet，那道門就是 router。[一個封包的旅程](article://packet-journey)走的就是它的世界。

**L3 switch。** switch 長出了 router 的能力。它同時讀 MAC 跟 IP，區網內用 L2 快轉，跨網段時用 L3 路由。大型內網的骨幹常是這種。

**Firewall，L3/L4 起跳。** 它讀 IP 加 port（[L4](chunk://l4-vs-l7-lb)），判斷這個封包放行還是擋掉。次世代的還會拆到 L7，看應用層的內容。它不是為了轉發，是為了過濾。

**Gateway，不是一個層級，是一個角色。** gateway 指的是「你這個網路對外的那道出口」，通常由 router 兼任。所以它談的不是 OSI 第幾層，是「在邊界上」這個位置。

順帶解開一個常見的混淆：你家那台「WiFi 分享器」，其實把 router、switch、AP **三台設備塞進一個盒子**。所以你會覺得它們好像是一種東西。企業環境裡，這三個通常是各自獨立的設備。

## 第二個維度：它擺在哪

OSI 層講的是「這台設備能做什麼決策」。但拓撲圖上還有另一種等級，講的是「它擺在哪、掛掉會牽連多少人」。

企業網路由外而內，大致是這樣一條鏈：

```
internet
  │
gateway / firewall     邊界，對外唯一出口
  │
core switch / router   核心，站內骨幹
  │
access switch          接入層，牆上網孔
  │
AP                     把無線裝置接進來
  │
client                 端點，不轉發任何人
```

越多設備的連線要經過它，它掛掉牽連的範圍越大。但牽連的**種類**不一樣。

gateway 掛了，整站連不出去，但站內設備彼此還通，因為內部流量根本不經過 gateway。core switch 掛了才可怕，那是站內的必經點，它一斷，內部大片區域直接失聯。一台 AP 掛了，只有連它的那幾台無線裝置掉線，範圍最小。

所以精確的規則不是「越上游影響越大」，而是**越多人的路要經過它，它掛掉的影響越大**。gateway 是「對外」的必經點，core switch 是「對內」的必經點，兩者擋住的是不同的路。

## 兩個維度不是同一件事

一個常見的錯覺是把兩個維度疊在一起，以為越上游的設備 OSI 層越高。不是。

gateway 在拓撲最上游，但它工作在 L3。AP 在邊緣，也是 L2。兩者的層級一樣，位置天差地遠。真正的關係是：

- **OSI 層**決定這台設備看得懂什麼、能做什麼判斷。用 MAC 還是 IP，能不能過濾，能不能跨網段。
- **拓撲位置**決定它掛掉會黑掉多大一片。維運告警的收斂、故障的牽連範圍，看的是這個。

## 要記的模型

分辨一台網路設備是什麼，先問它拆封包拆到第幾層。讀 MAC 是 switch 跟 AP 的世界，讀 IP 是 router 的世界，讀到 port 以上是 firewall 的世界。

再問它擺在拓撲的哪一格。這決定它掛掉的時候，是一台裝置掉線，還是一整層樓黑掉。一台設備是什麼、以及它出事有多嚴重，就由這兩個問題一起回答。
